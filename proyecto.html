DISEÑO Y EXPERIENCIA

Una web pensada para recorrerla.

SIAM / 27 reúne en un mismo lugar la ruta, los preparativos y las ideas del viaje. Cada apartado tiene una función propia y mantiene una identidad visual común.

↗

Información ordenada

Seis apartados para consultar destinos, organizar el viaje, explorar artículos y reunir recuerdos.

◐

Diseño adaptable

Una interfaz que se ajusta a móviles y ordenadores, con navegación sencilla y temas claro y oscuro.

✓

Elementos interactivos

Cuenta atrás, checklist de preparación, selección de artículos, filtros de bitácora y notas personales.

⌁

Explorar el mapa

La ruta combina un mapa interactivo con una guía escrita para recorrer las principales paradas.

✳

Una identidad propia

La paleta de tinta, papel, coral y salvia acompaña la temática del viaje con un estilo editorial cálido.

＋

Turismo responsable

La planificación pone en valor la cultura local, el respeto por los espacios naturales y la conservación de la fauna.

TECNOLOGÍAS

Sencilla por fuera, cuidada por dentro.

La estructura está construida con tecnologías web estándar y componentes compartidos entre las páginas.

HTML

Organiza el contenido y la estructura semántica de cada página.

CSS

Define el sistema visual, la distribución adaptable y las transiciones.

JavaScript

Añade la cuenta atrás, los filtros y las interacciones de la página.
